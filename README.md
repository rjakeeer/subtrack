# subtrack — Сервис учета цифровых подписок

Веб-приложение для централизованного учета периодических платежей за цифровые сервисы (кинотеатры, музыкальные стриминги, софт, облачные хранилища). Проект разработан в рамках учебной дисциплины «Технологии программирования».

## 💻 Стек технологий
* **Бэкенд:** Python 3.11+ / Django 5.0 / Django ORM
* **Аналитика и визуализация:** Matplotlib (генерация круговых диаграмм на стороне сервера в буфер)
* **Интерфейс и стили:** HTML5 / CSS3 / Bootstrap 5 (автономная интеграция через пакет `django-bootstrap5`)
* **База данных:** SQLite

## 🚀 Ключевые возможности (Функционал)
1. **Система ролей и авторизация:** Полное разделение прав. Для гостей доступна посадочная страница с техническим описанием, а личный кабинет полностью изолирован для каждого пользователя.
2. **Двухшаговый CRUD-контроль:** Интерактивный каталог популярных шаблонов для быстрого добавления подписок и отдельная интеллектуальная форма для создания кастомных сервисов.
3. **Автопродление дат на чистом Python:** Автономный сдвиг просроченных дат списания на месяц/год вперед при авторизации пользователя (без использования Cron/Celery).
4. **Умная бэкенд-оптимизация:** Поиск избыточных подписок внутри одной категории и выявление точных дубликатов сервисов с возможностью скрыть плашку уведомления.
5. **Фильтрация и динамический поиск:** Быстрый поиск по каталогу шаблонов с использованием ORM `Q`-объектов с полной поддержкой кириллицы.
6. **Интерактивное финансовое планирование:** Встроенный блок микро-расчета будущих затрат на периоды от 3 дней до 1 месяца и круговая диаграмма расходов.


## 🔧 Локальное развертывание (Инструкция)

### 1. Клонирование репозитория
```bash
git clone https://github.com/rjakeeer/subtrack
cd subtrack
```

### 2. Настройка виртуального окружения
**Для Windows:**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Для Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash/powershell
pip install -r requirements.txt
```

### 4. Создание базы данных и применение миграций
```bash/powershell
python manage.py migrate
```

### 5. Создание суперпользователя (Администратора)
```bash/powershell
python manage.py createsuperuser
```

### 6. Запуск сервера разработки
```bash/powershell 
python manage.py runserver
```
После запуска проект будет доступен в браузере по адресу: 127.0.0.1:8000 (8000 дефолтный порт, если хотите поменять python manage.py runserver 1234)
